# 🚖 RideCo – Real-Time Ride Sharing App

RideCo is a real-time ride sharing mobile application developed using Flutter, Dart, and Firebase.  
The project is designed to provide a smooth, secure, and efficient ride booking experience for both drivers and passengers through real-time system functionality.

---

## 🚧 Project Status
This project is currently under active development.

---

## ✨ Features
- User Authentication
- Real-Time Ride Booking
- Driver & Passenger Modules
- Firebase Integration
- Live Ride Updates
- Ride History
- Notifications System
- Responsive Mobile UI

---

## 🛠️ Tech Stack
- Flutter
- Dart
- Firebase

---

## 📱 Project Goal
The main objective of RideCo is to create a scalable and user-friendly ride sharing platform that enables passengers to book rides efficiently while allowing drivers to manage ride requests in real time.
